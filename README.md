# Excalidraw Low Latency

An Obsidian companion plugin that applies a low-latency pen profile to open Excalidraw views.

It reduces smoothing and streamline processing, supports linear easing, removes stroke taper, and restores the original Excalidraw stroke settings when disabled.

## Install

Copy `main.js`, `manifest.json`, and `styles.css` if present into:

`.obsidian/plugins/excalidraw-low-latency/`

Enable the plugin after installing Excalidraw.
